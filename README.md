# Child Reach
## Identifying Child Vulnerability Hotspots in Mozambique Through Spatial Data Fusion

ChildReach identifies areas where multiple publicly available vulnerability indicators overlap and provides an explainable spatial prioritization to support further assessment and decision-making.

### Milestone:
- Build and understand a district-level map of Mozambique showing estimated population under age 18.

### Ethical Framing:
- This project supports further humanitarian assessment; it does not determine aid allocation or identify individual children.
